# Lista de comprobación visual

Ejecuta `pnpm dev` y revisa las páginas en anchos aproximados de 375 px (móvil), 768 px (tablet) y 1440 px (escritorio).

- [ ] Navegar por Home, Portafolio, detalle de proyecto y CV; verificar que el estado activo del navbar coincide con la página.
- [ ] Revisar que las tarjetas no se desborden y que los textos largos se ajusten correctamente.
- [ ] En CV, usar el índice de secciones y abrir varios certificados en una nueva pestaña.
- [ ] Bloquear temporalmente las imágenes de `platzi.com` y confirmar que el fallback de certificado se muestra.
- [ ] Abrir una ruta inexistente y comprobar la página 404 y sus dos enlaces.
- [ ] Recorrer los enlaces con teclado y confirmar que el foco es visible.
- [ ] Activar `prefers-reduced-motion: reduce` en las herramientas del navegador y verificar que el contenido se mantiene visible sin animaciones.
- [ ] Revisar la consola del navegador para errores de red, imágenes o scripts.

La compilación estática valida enlaces internos y recursos locales; las comprobaciones anteriores complementan la revisión visual manual.
